- 프레임워크 :: 특정 목적(웹, 앱, ...)에 맞추어, 보다 편리하게 개발하기 위한 도구 상자
   - SpringBoot :: 웹개발 목적 Java 기반 프레임워크
- 의존성(Dependency) :: 라이브러리(Library), 여러 명령어들을 체계적으로 갖춘 것
   - 어노테이션(@) :: 의존성의 기능들 중 하나

< 파일 역할 >
- src/main/java :: [프로젝트 중심] 사용자 화면(.html)-서버(localhost, DB) 간의 동작 정의
- src/main/resources :: .java 실행에 필요한 자원(.html, .css, .js, ...) 저장
   - application.properties :: [차후 설명]
- build.gradle :: SpringBoot 프로젝트 설정값 저장
