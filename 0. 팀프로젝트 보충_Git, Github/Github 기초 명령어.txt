* 일반적인 순서 ::
1. 기존 작업물 pull (다운로드)
2. 기존 작업물에 대해 작업 수행 (코드/설명 추가, 수정, 삭제, ...)
3. 2의 변경사항 github push (업로드)


- git init :: git 명령어를 쓸수있게끔 사전 작업 명령어
   (실행이 되면, .git 숨김폴더 자동 생성)

- git branch -m main (브랜치 이야기한 후 설명)

* git pull [원격_레포지토리_주소] main ::
   지정된 레포지토리의 내용을 로컬로 다운로드

[업로드 진행하기 전, 계정 주인임을 밝히기]
- git config --global user.email "[계정_이메일]"
  git config --global user.name "[계정_이름]"

* git add [파일명] :: 변경사항 확인할 파일 지정
   (git add . :: 모든 파일 지정)

* git commit -m "[메시지]" :: 변경사항 확인 (메시지 남김)

* git push [원격_레포지토리_주소] main ::
   원격저장소와 겹치지 않는 내용(변경사항) 업로드
